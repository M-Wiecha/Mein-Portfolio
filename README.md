# 💻 Mein Professionelles Webdesign-Portfolio

Willkommen im Repository meines offiziellen Webdesign-Portfolios, erreichbar unter [mario-wiecha.de](https://mario-wiecha.de). Diese Website dient als digitale Visitenkarte für meine Arbeit als freiberuflicher Webdesigner (Kleinunternehmer). Sie kombiniert modernes, interaktives Design mit höchsten Ansprüchen an Performance, native Code-Struktur und kompromisslosen Datenschutz.

---

## ✨ Design-Philosophie & Features

Das Interface wurde mit Fokus auf Ästhetik und Nutzererfahrung (UX) entwickelt. Zu den wichtigsten visuellen und funktionalen Merkmalen gehören:

* **Modern UI Customizing:** Einbindung von eleganten **Glassmorphism-Effekten**, tiefen Dark-Mode-Layouts und fließenden, interaktiven CSS-Hover- und 3D-Card-Effekten.
* **Dynamic UX Elements:** Ein maßgeschneidertes, interaktives modales Fenstersystem und animierte Call-to-Action-Elemente (z. B. "pulsierende" Buttons).
* **Individuelles Projektanfragen-System:** Ein sicheres, PHP-basiertes Multi-Card-Anfrageformular, das potenzielle Kunden Schritt für Schritt durch die Projektdefinition führt.
* **Datenschutz & DSGVO-Konformität (100% CDN-frei):** Alle Bibliotheken und Assets sind vollständig lokal eingebunden. Es werden keine externen CDNs (Content Delivery Networks) geladen. Das garantiert maximale Ladezeiten-Optimierung, vollständige Offline-Funktionalität und absolute DSGVO-Konformität.
* **Zukunftssicheres SEO & GEO:** Optimiert durch strukturierte Daten (**JSON-LD Schema**) für traditionelle Suchmaschinen sowie für die Auffindbarkeit durch KI-Modelle (Generative Engine Optimization).

---

## 🛠️ Technische Details & Tech-Stack

Das Portfolio wurde von Grund auf nativ entwickelt, um die volle Kontrolle über die Performance und den Quellcode zu behalten:

* **Frontend:** HTML5, CSS3 (inklusive modernen Grid/Flexbox-Layouts), Vanilla JavaScript (ES6+).
* **Backend:** PHP (für die sichere Verarbeitung und Validierung des Projekt-Inquiry-Formulars).
* **Lokale Bibliotheken (Kein CDN):**
    * **SweetAlert2:** Für stylische, responsive Feedback- und Bestätigungs-Modals.
    * **Font Awesome:** Lokale Bereitstellung aller Icons für optimiertes Asset-Streaming ohne Drittanbieter-Anfragen.

## ⚙️ Installation & Lokale Entwicklung

Da das Projekt auf nativem Code und lokal gehosteten Assets basiert, lässt es sich extrem unkompliziert lokal aufsetzen.

### Voraussetzungen
* Ein lokaler Webserver mit PHP-Unterstützung (z. B. XAMPP, MAMP oder integriertes PHP).
* Ein Code-Editor (z. B. VS Code).
