# Mein Portfolio

Willkommen auf meinem Portfolio! Hier zeige ich meine Webentwicklung-Projekte und meine Fähigkeiten.

## 📋 Über dieses Projekt

Dieses Repository enthält mein persönliches Portfolio, das meine Fähigkeiten und Erfahrungen in der Webentwicklung showcaset.

## 🛠️ Technologie-Stack

Das Projekt ist mit folgenden Technologien gebaut:

- **HTML** (39.4%) - Struktur und Markup
- **CSS** (35.8%) - Styling und Layout
- **JavaScript** (21.4%) - Interaktivität und Funktionalität
- **PHP** (3.4%) - Backend-Logik

## 📁 Projektstruktur

```
Mein-Portfolio/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── script.js
└── README.md
```

## 🚀 Installation & Nutzung

1. Repository klonen:
```bash
git clone https://github.com/M-Wiecha/Mein-Portfolio.git
cd Mein-Portfolio
```

2. Die Dateien lokal öffnen oder auf einen Webserver hochladen

3. Im Browser öffnen und das Portfolio ansehen

## ✨ Features

- Responsives Design
- Interaktive Elemente mit JavaScript
- Modernes und ansprechendes Layout
- Backend-Unterstützung mit PHP
